# RouteWise demo

Playground + dashboard for RouteWise, an OpenAI-compatible LLM gateway with a learned
cheap/strong router and a verified semantic cache.

Source code, evaluation reports and docs: see the GitHub repository linked in the main README.

Secrets this Space needs (Settings -> Variables and secrets):
`GROQ_API_KEY` (required), `GEMINI_API_KEY` (optional fallback), `ROUTEWISE_API_KEYS`.
